# Tic Tac Toe

## Description
This is Tic Tac Toe program.<br>
That when the main.rb file is run will allow two people to play a game of tic tac toe in the terminal.<br>
I made it for the [Tic Tac Toe project from the Odin Project](https://www.theodinproject.com/lessons/ruby-tic-tac-toe)

## How to run

### Prerequisites
The ability to run ruby 3.4.6 code. (I don't know if it works on other versions of ruby)

### Running the program
Clone or, download and extract, the repository in a folder.<br>
Open up a terminal in the folder and run "ruby main.rb" without the quotes.<br>

## Rules
The starting player places their piece in an empty space on a three by three grid.<br>
The next player places their piece in an empty space on the grid.<br>
Players continue taking turns until one player wins or the board is full.<br>
Players can win by having three of their pieces in a row that is either horizontal, vertical, or diagonal.<br>
If the board is full and no player has gotten three of their pieces in a row then game ends in a tie.
